# KI Trading Bot

Paper-Trading-Dashboard: Ein Bot handelt mit Spielgeld auf Basis echter Live-Kurse (Krypto über Binance, US-Aktien über Finnhub) und zeigt Depotwert, Gewinn/Verlust, Positionen und jede Entscheidung mit Begründung.

**App öffnen:** https://h-shyp.github.io/ki-trading-bot/

Es werden keine echten Orders ausgeführt.
